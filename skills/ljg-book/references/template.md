# {用开头那个具体处境、困惑或人物时刻命名}

{让读者进入一件可以看见的事。它可以是一次选择、一个最小模型、一个人物时刻、一段关系或同一问题在某个条件下的结果。先让读者按常识形成理解，不要预先宣布它错了。}

{若使用自建讲解对象，用“想象一下”“先拿”“试着”自然进入。身份、旧稿依据与核验状态只写在 coverage；正文只写它能回答什么、还需哪些现实条件，不写免责句。}

{放入书中的一个事实、事件、后果或相邻案例，让原来的理解具体地不够用。只揭开当前缺口，不连续展开整套理论。}

{最迟到第二个一级标题结束，陌生读者应能说出这是什么形态的书、实际跟着谁或什么走、主要运动方向与不可省略的另一条线；不要改成“本书讨论……”的场外摘要。}

# {用使原理解发生变化的事件、结果或新问题命名}

{引入刚好能补上缺口的一条关系、条件或区分。概念只在读者已经感觉需要时出现。随后回看原来的处境，写清什么已经改变。}

{让改变后的结果自然提出下一问。下一标题不是新的重点摘录，而是回答这个尚未解决的问题；段首先承接上一结果，再进入新对象。若当前扶手还能承载，就继续沿用；必须换人物、年代、对象或场景时，由前一结果说明为什么现在非换不可。反例要真正改变判断，不写成清单。按真实需要复制这个“标题 + 转折”块，不预设章节数量或篇幅上限。}

{最后在真实的最后一个标题下回到最初的处境或困惑。不加入新术语。写清读者现在会先看什么、先问什么、怎样重新判断，或者为什么愿意保留一个更准确、无法轻易消掉的矛盾。}

# 读完后留下什么

{只写一个自然段，通常一到四句：如果作者走完全书，只能让读者真正明白一件事，那是什么？用极直白的话说清作者在纠正什么、重新连接什么或保留什么。结构、洞见、模型、矛盾、意象和书名解释只用于后台寻找答案，不写成标签或清单。书名承重就自然回答书名，不承重就不强求。这里只压缩正文至少两个相隔转折已经讲清的关系，不加入新概念、新证据、新建议或章节摘要。}
