# ljg-book 材料与检查记录

这份记录供研究、取舍和检查使用，不直接作为成品提纲。没有证据时写「未找到」，不能用推测补空。

冒号前的字段名供验证脚本读取，保留现有写法；填写时按旁边的说明，用日常话回答。「扶手」指贯穿文章的问题、人物或关系；「生成器」指书中能解释多处变化的关系；「载体」指正文选用的案例、人物、比较或模型。这些名称不要求出现在正文里。

- 覆盖合同版本：2
- 材料等级：{完整拆书 / 初拆 / 假设版}
- 主要材料：{实际读到的全文、样章、目录、访谈或可靠评论；写明版本或路径}
- 能支持到：{足以支持哪些判断，不能支持哪些判断}
- 材料能否支撑认识更新路径：{是 / 否——是否足以说明最初怎样理解、什么使它不够、作者增加了什么关系、后来怎样重新看；若否，先补材料或缩小输出}

- 字面上跟着谁、什么对象或什么问题展开：
- 起点、主要变化与终点：
- 不可省略的主线：
- 主线为什么属于同一本书：
- 正文必须出现的整书锚点：{用精确短语记录能让人认出原书的具体人物、事件或论述；完整拆书至少 3 个，按需要增加，不设上限；初拆或假设版至少 1 个，都有材料支持；用 `｜` 分隔；不用「问题、关系、变化、结论」等通用词}
- 三十秒整书复述：
- 可迁移性反测：{若换一本书仍然成立，指出缺失了哪个对象、过程、关系或结尾}

## 读者的理解怎样改变

材料能够支撑时填完。读者在术语出现以前先有自然的理解，再看见它为什么需要补充或改变。不要求套齐一组动作。

- 读者进入什么具体处境：
- 最初最自然会怎样理解：{这个想法为什么可信或有吸引力；涉及人的选择时，材料支持怎样的愿望与顾虑，改变想法会放下什么}
- 哪个事实、事件或结果让它不够：
- 作者增加了什么关系或条件：
- 回看原处境，什么已经改变：{写清理解有何不同；只有行动或条件确实改变并带来新后果时，才写结果变了}
- 新结果自然带出什么问题：{新的理解或实际后果，让读者接下来还需要问什么}
- 贯穿全文的扶手：{贯穿文章的问题、人物、关系或模型，为什么适合这本书；换场时读者原有的关切怎样得到延续}
- 结尾回到哪里：
- 陌生读者能怎样复述：
- 原书依据与简化边界：

最后一项完整记录例子是否自拟、依据哪些原书内容、做了什么简化、不能推出什么。正文用「想象一下」等说法自然引入自拟例子，再说明它能解释什么、还需什么条件，不插入查资料或改稿的过程。第一人称和原书人物的写作活动本身没有问题。

## 哪些关系贯穿了全书

检查书中是否有能解释多处关键变化的函数、因果关系、过程、人物选择或贯穿矛盾。下面沿用脚本字段名「生成器」。没有共同解释就写「否」，不强行归纳成公式。

- 是否存在全书生成器：{是 / 否——为什么}
- 全书生成器：{用日常话写清反复起作用的关系，必要时保留公式；若不存在写「未找到」}
- 输入、起点或当前状态：{什么进入这条关系}
- 结果方向或终点：{什么算变化，朝哪边算更好、完成或更接近作者的问题}
- 生成器怎样贯穿至少两个远距转折：{指出书中相隔较远的两处关键转折，说明同一关系怎样分别解释它们}
- 生成器在哪些条件、范围或层级失效：{反例、阈值、换层或无法消除的矛盾}
- 正文生成器锚点：{正文中能精确找到的短语；多个用 `｜` 分隔}
- 生成器是否需要在前两个一级标题内运行：{是 / 否——为什么；分析与理论通常先用例子讲清基本关系，叙事需要逐渐揭示时可写否}
- 是否需要视觉表示：{是 / 否——曲线、空间、层级、顺序或精确映射是否仅靠文字难以保持}
- 视觉表示后用哪个载体运行：{图表之后紧接着用哪个例子说明怎样读图，填写正文中的精确名称；不需要图表时说明怎样直接用例子讲清}

## 正文选用哪些例子

候选材料可以很多，正文只选讲清全书需要的人物、事件、模型或比较。每个例子都要带来前面尚未讲清的东西，并能说明起点、结果、理解的变化与接下来的问题。「改变的关系」填写读者新看明白的关系；只有事情本身发生变化时，才写实际关系变了。

- [frontstage] 名称：｜唯一职责：｜设置或起点：｜结果或后果：｜改变的关系：｜下一问：

- 正文中哪两个相隔较远的转折共同托住它：{至少写明两处，说明它们怎样共同支持末节的这句话}

## 内容是否连贯

- 开篇留下的真实问题：{读者继续读时仍想弄清的具体问题，不填主题词}
- 转折链：{按正文顺序说明读者原来怎样理解，哪些事实或对照补上了什么，后来明白了什么，还有什么要问；不设段数上限}
- 每次换场为什么不可提前：{字段名沿用旧版；填写与前文的实际联系及当前位置的理由。若可以提前，如实说明，不编造必须先后发生的关系}
- 换序测试：{交换相邻小节，观察前提、对照或认识变化是否受影响；可以换序时，说明共同问题与当前安排的理由。仅有主题相同而无实际联系时再补写，不单凭可换序判定失败}
- 摘句拼接反测：{某段若只保留案例名或关键句，会遗漏哪段事实、因果、对照或理解的变化}
