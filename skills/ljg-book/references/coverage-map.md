# ljg-book 材料与检查记录

这是研究与核对记录，不是正文提纲。冒号前字段名由脚本读取，保留写法。字段填写只能证明记录存在，不能证明解释正确或文章好读。没有材料时如实写清，不以推测补齐经历。

## 材料边界

- 覆盖合同版本：3
- 材料等级：{完整拆书 / 初拆 / 假设版}
- 主要材料：{实际读过的版本、路径或来源；全书阅读范围与未读部分}
- 能支持到：{可以解释哪些内容；不能支持哪些内容；若需补材料，记录结果}
- 材料能否支撑认识更新路径：{是 / 否——原有理解、压力与变化是否有依据；材料不足时不升级为完整拆书}

## 全书怎样构成整体

核心理解、部分关系和作者关切在这里各记录一次；不要在不同栏里反复改写同一句总论。多线作品按实际内容说明，允许并列、对照或无法统一的矛盾。

- 这是什么类型或形态的书：
- 起点、主要变化与终点：{具体对象或人物、重要过程、结尾与未决部分}
- 核心理解：{最初怎样理解；什么内容迫使补充或改变；修订后怎样看}
- 各部分怎样相连：{不可省主线及各自作用；依赖、分工、因果、对照或限制；不能只写共同主题}
- 作者最想纠正或保留什么：{从原书取舍与发展推知，并给出依据；不虚构作者心理}
- 正文必须出现的整书锚点：{正文选用、具有材料依据的具体短语；完整至少3个，部分至少1个，用｜分隔；不以增加数量证明完整}

## 正文沿哪些线索展开

每行记录一个持续展开的问题、人物、关系或模型。一个线索可以经过多个阶段、承担不同作用；不为每个概念另建一个例子。换场确有必要时，说明承接的关切及新增作用，不强守同一个物件，也不限制线索数。

- [thread] 名称：｜起点：｜关键推进：｜前后变化：｜换场理由：｜依据与边界：

「前后变化」写出原来和后来的实际判断、条件或含义；无行动结果时不要编造。自拟情景与原书事实在「依据与边界」中分清。正文让这些关系展开，不照着字段报幕。

## 成品阅读检查

先给评估者成品，再把其实际回答写在这里；不要把这里的答案交给评估者。来源忠实度另行回查原文。记录具体阅读位置和结果，不只写PASS。

- 整书复述与关系重建：{类型、对象、起点变化终点、必需主线及分工、未决问题；共同解释与迁移；支撑复述的正文展开，不能仅摘抄概况段；评估者和检查范围}
- 阅读断点与修订：{哪里缺了关系、过早换对象或引入名称，或退到书籍简介与写作说明；切换的实质必要性；哪两段显示实际理解变化；怎样修订及复读结果；未发现时记录依据}
- 遮住末节后能否理解作者关切：{正文哪些发展已使关切可见；有没有靠末节补进新道理或重复收束}
- 正文中哪两个相隔较远的转折共同托住它：{它指末节的意思；指出两处及其共同作用，不另写一份精神内核}
