# Reading Guide：后台读全，前台让认识一步步改变

这份指南负责研究与取舍。成品不是覆盖记录的翻译，而是一条普通读者能够亲自走过的发现路径。

## 先锁材料边界

每次任务复制 `references/coverage-map.md`，记录材料等级、实际来源和支持边界。

- **完整拆书**：全文或等价材料足以追踪全书问题、对象、机制与边界。
- **初拆**：只有目录、样章、访谈、可靠评论或旧笔记，只能形成局部理解。
- **假设版**：资料更薄，只能提出有标记的暂定判断。

再回答“材料能否支撑认识更新路径”。判断标准不是有没有摩托车、手机、实验这类名词，而是材料能否说明：人最初怎样理解，哪件事使这种理解不够，作者又增加了什么关系，最后怎样重新看原来的问题。

如果不能，不要把泛化概括写成现场。继续找原文；找不到就缩小输出，明确只解释材料支持的局部。证据边界高于叙事感染力。

## 全文材料怎样读

完整拆书先覆盖四类证据：

1. 作者为什么非处理这个问题不可。
2. 作者怎样建立最初处境、人物关系或基本区分。
3. 什么使原来的理解不够，作者怎样改写。
4. 最后形成什么判断，在哪些条件前停下。

再列至少 5 个候选部件，记录位置、作用、连接关系和删除测试。复杂或篇幅大的书按实际转折继续增加，不设上限。它们帮助判断什么不能漏，却不直接决定正文目录。

## 先锁整书身份，再选择贯穿困惑

认识更新需要一个稳定的困惑，整本书还需要一张不会被困惑吞掉的身份证。选择前台扶手以前，先用日常话锁定：

- 这是什么类型或形态的书；
- 字面上跟着谁、什么对象或什么问题展开；
- 它从什么起点，经过哪些主要变化，走到什么终点；
- 哪些主线不可省，以及它们为什么属于同一本书；
- 哪些来源特定的对象、事件或关系必须在正文出现；完整拆书至少 3 个，按实际叙事需要增加，不设上限。

随后才把全书变成一个普通人能够进入的困惑。困惑负责让读者向前走，不负责替代整本书。若一个关于“自由、质量、未知、成长”的判断成立以后，原书的人物、对象、运动轨迹和结尾都可以删掉，得到的是主题文章，不是完整拆书。

好的困惑带着尚未解决的冲突，例如：

- 既然问题这么严重，为什么这个解决办法还没有被证明？
- 照着手册做为什么仍然修不好眼前这台机器？
- 同样的数字只换一种说法，人的选择为什么翻了？
- 规则在小范围有效，放大以后为什么反而制造故障？

“这本书讨论自由、质量、决策”不是读者困惑，只是主题标签。

## 找到贯穿全文的扶手

一个好扶手不一定是物件，也不一定从头到尾保持同一种形态。它可能是：

- 一次读者可以立即重做的选择；
- 一组可以代入的数字或公式；
- 一个能连续改变状态的日常物件；
- 一个旧做法会得到明确结果的小任务；
- 原书人物正在面对、且材料足以还原的具体时刻；
- 一个跨越不同年代仍在追问的问题；
- 一段不断变形却没有消失的关系或矛盾；
- 一条选择、后果与再次选择组成的因果链。

入口要足够小，使读者不用先学背景就能进入。扶手要足够稳定，使读者始终知道眼前在追问什么。为了保持同一个物件而扭曲全书，比自然换场更糟；换场时只需让前一个结果说明为什么必须换。

检验扶手是否成立：删掉解释后，读者仍能说出“原来怎样理解—哪件事让它不够—后来多看见了什么”；删掉书名以后，仍能说出成品实际跟着什么走了一遍、哪些主线为什么相连。只剩一个寓意，或只剩一条可以换书复用的认识曲线，都只是配图。

## 场景摘要与可运行现场

摘要会把一段时间压成结论：

> 父亲会听机器的声响、检查原因，并根据反馈调整。

它交代了正确事实，却没有留给读者任何未知。能让认识改变的现场需要一个确定时刻：某种理解先成立，随后一件事使它不再够用，人不得不重新看。

不要为了近景虚构零件、天气、对话、表情或心理。若原书材料没有给出这个时刻，说明材料门没有通过，不是文笔还不够好。

## 一次认识转折怎样成立

一次转折只需要完成一项认识变化：

```text
进入一个具体处境
→ 形成一种自然理解
→ 事实、事件或结果让它不再够用
→ 加入刚好能补上缺口的新关系
→ 回看原来的处境，结果已经改变
→ 新结果自然带出下一问
```

这不是要求正文显示六个步骤，而是用来检查转折有没有跳跃。实际文章可以用选择、比较、人物遭遇、制度变化、模型故障或一个不断加深的矛盾完成它。读者不需要听见写作者的设计，只需要顺着事情自然走过。

概念在读者感到需要以后出现。它可以紧跟一个结果，也可以等两个案例并排、一次选择付出代价或一个矛盾反复出现以后再命名。命名后马上说明它补上了什么；不要停下来集中讲一套定义。

## 一本书怎样继续向前

全书只保留理解主干所需的转折。每次只增加一个新关系，但始终由开头的困惑牵引。

转折不是把全书切成若干“重点案例”。它是一条依赖链：读者在这一段形成的理解，必须在这里遇到具体压力，才需要下一段的新对象、新层级或新概念。若删掉段尾和段首的过渡词，两个案例仍只是并排摆放，就没有形成叙事。

优先沿用已有扶手。例如一段手机政策论证可以依次承受：理由与结论的缺口、何种证据能填缺口、替代解释怎样改变政策选择。每一步都回到“现在是否足以支持加重处罚”，而不是分别介绍专家、调查、统计、因果和遗漏信息。

只有当前载体确实承载不了下一关系时才换。前一个结果要提出换场的理由：最小模型在扩大时失效，人物离开一个关系进入另一个关系，同一制度换到新条件下产生相反结果。

后台的全书困惑负责连续性；前台选择的扶手负责降低认知负担。

写完以后做换序测试：任取两个相邻一级标题交换位置，指出读者会在哪个未解决问题、必要前提或认识变化上断裂。若多数标题可以自由换序，说明正文按“关键语句/案例”采样，而没有重建作者的发现脉络；回到作者为什么必须从前一问题走到后一问题，补足中间事实与转折。

## 不同书型怎样带读者向前

### 分析与理论

让读者先完成一次自然判断，再用书中的区分、反例或证据改变判断。概念出现后，回到原判断，看它具体改变了哪一步。

### 方法与实践

让旧做法与新做法各得到一次结果。若作者改变了“什么算有效”，结果标准也要在对象上显出来，而不是附加成建议。

### 技术与科学

建立一个读者能手算、跟踪或预测的最小模型。先让它工作，再用规模、故障或边界迫使模型增加一层。这里最适合沿用“预测—结果—修正—重跑”，但不要把这种形式推广到所有书。公式保留时，下一句说明数字正在做什么。

### 历史与社会

多个场景可以换，但每次仍回答同一个困惑。稳定的是问题或因果关系，不必是同一人物与物件。不要为了年代覆盖切换人物；新条件真正改变了结果才换场。

### 传记与叙事

跟随一个选择怎样得到后果，后果又怎样改变下一次选择。人物的认识、关系或处境可以承担扶手。不要把漫长人生压成成功方法，也不要把每次经历都改写成即时反馈。

### 文学与哲学

使用材料能支撑的具体人物时刻、关系变化、反复意象或论证困境。认识更新可以表现为“原来忽略的关系终于被看见”，不必得到一个办法，也不必消除矛盾。人物经历本身可以是结果。没有具体书内时刻时，先补材料。

## 证据怎样进入而不压垮正文

证据只在它改变读者当前理解时进入。

不要一次列出所有证据类型。先问眼前缺的是哪一块：问题是否存在、原因是否成立、办法是否有效、代价是否可接受。随后只放入能回答这一个问题的证据，让它改变当前理解。

原书案例、作者解释和自建讲解对象仍要分清，但这项分工先在后台完成：

- 原书材料决定结论能走多远。
- 作者解释说明他怎样理解材料。
- 自建对象只帮助读者看见关系；它的来源、简化和支持边界完整记在 coverage。

正文不要把后台记录翻译成免责声明。自建对象用自然动作进入：“想象一下”“先拿十二根纸条”“把最后一句遮住”。到了边界，不说谁构造、依据哪份旧稿或本轮核到哪里，只说眼前对象能回答什么、还缺哪些现实条件。

不要这样写：

> 纸条与书由讲解者根据现有旧稿构造，不是本轮核到的书内案例，也不能替钢材计算强度。

让边界仍在事情里面发生：

> 纸条不会告诉你钢梁能承受多少吨，却已经把问题拨正：决定结果的不只有材料，还有材料怎样连成一个整体。真正计算钢材时，截面、缺陷和载荷才接着进场。

前一句在报告写作过程，读者会突然看见讲解者；后一句仍盯着纸条，同时知道这一步走到了哪里。证据诚实没有减少，只是从责任声明变成了对象的能力边界。

## 口头稿先于书面压缩

先按说给一个聪明朋友听的方式读回正文。好的节奏通常是：短问句保留真正的未知，具体事情推进理解，短答句确认刚看见的变化。允许重复同一个普通词，不急着用同义词显得丰富。

朗读时若一句话像在向审稿人交代资料身份、核验范围或责任，先删掉再听一遍。需要保留的来源事实移回 coverage；需要保留的理解边界，改写成对象还能回答什么、下一步必须加入什么。正文中的句子应该推动眼前的事情，而不是解释作者为何这样写。

每段通常一到三句，只增加一个关系。连续出现三个以上抽象名词时，检查是否跳过了中间事实、事件或后果。警句最后再写；若删掉警句以后机制不见了，说明中间没有讲清。

篇幅没有预设字数、目标区间或上限。完整解释何时结束，只由读者是否已经自然走完作者的关键转折决定。复杂书需要更多步骤就增加篇幅，并用标题、留白、重复扶手与具体场景保持可读；只有材料不足或用户明确要求局部解释时才缩小范围，绝不为了短而提高概念密度或删掉过桥过程。

## 标题与返程

标题写读者正在面对的问题、事件、变化或结果。它要让人只看标题也能看到理解怎样向前，而不是看到一组漂亮的分析结论。

开头仍从具体处境进入，但最迟到第二个一级标题结束，读者应当已经认出整书的主要对象或问题、字面运动和不可省略的另一条线。这里不需要站到讲台上概括“本书讨论什么”；让人物、对象、路线或论证本身把方向交代清楚。

结尾回到最初的问题，不加入新术语。写清同一个读者现在会先看什么、先问什么、怎样重做那项判断，或为什么愿意保留一个无法消掉的矛盾。

若返程可以放进任何一本书，说明它没有回到这本书开头的困惑与扶手。

## 陌生读者验收

机械检查之后，只给评估者最终成品，不给 coverage、原书或预期答案。先回答整书识别四问：

- 这是什么样的一本书？不能只回答一个主题。
- 书里实际跟着谁、什么对象或什么问题，从哪里走到哪里？
- 哪些主线不可省，它们为什么被写在一起？
- 结尾实际发生或形成了什么，什么仍然未知或没有被解决？

四问任一项只能回答抽象主题，停止交付。找到最早把主要对象、运动过程或必要主线降成“例子”的位置，恢复整书身份以后再继续。

四问通过后，再回答认识更新九问：

- 开头让我进入了什么具体处境、困惑或人物时刻？
- 我一开始最自然会怎样理解？
- 哪个事实、事件或结果让这种理解不够用了？
- 新加入的关系补上或照亮了什么，原来的事情怎样改变？
- 为什么下一段必须从上一段生出来？
- 交换任意两个相邻一级标题，理解会在哪个具体问题、前提或转折处断裂？若几乎无损，是否仍是可换序的摘录拼盘？
- 不使用术语，能否复述书中改变的判断？
- 结尾回到开头以后，我现在会怎样重新看那件事？
- 有没有一句让人突然看见讲解者、旧稿、核验过程或免责声明？

若回答只能引用摘要、术语或结论，或相邻标题交换后几乎无损，回到最早失去处境、证据、依赖关系或因果连接的段落；若最后一题能指出一句，把后台事实移回 coverage，再用对象的能力范围收住。不要用“接下来”“另一个例子”补假桥，也不要在结尾补一段“换句话说”或免责声明。整书识别与认识更新是两张独立成绩单，不能互相补分。

## 写入与验证

Markdown 使用 `references/template.md`。正文完成后补 `description`，保留 Denote 文件名与 `identifier` 一致。

运行：

```sh
bun {skill_dir}/scripts/validate_note.ts /absolute/path/to/note.md \
  --coverage /absolute/path/to/coverage-map.md
```

validator 检查来源边界、覆盖记录、完整拆书的整书身份字段、正文锚点、叙事连续性字段、结构与若干可读性退化信号。它不会替代成品限定的整书四问与认识九问。

保存到 Denote 目录以后，再用真实 Emacs 读回：确认 `denote-retrieve-filename-identifier` 与文件名一致，`denote-file-has-denoted-filename-p` 为真，文件出现在 `denote-directory-files` 与 consult-notes 中。若正在运行的 Emacs 服务不可用，就使用能加载本机 Denote、consult 与 consult-notes 的批处理 Emacs；验证器不可用时明确延期，不把未执行写成通过。
