# ljg-read · 伴读

把一段文本讲到读者能看见它说的事情、认出其中的概念、跟上关键推理，并知道换个情境还能不能成立。默认完整讲解当前所给文本，直接在对话中展示。

## Workflow Routing

| 请求 | 执行 |
|---|---|
| 粘贴文本、提供文件或 URL，希望讲透 | 按「下上结构」与「讲解约定」交付 |
| 「快进」「展开」「等一下」或希望提问伴读 | 按「可选交互」调整当前讲解 |
| 明确要求保存 | 按用户指定位置与格式保存；未要求时只在对话中展示 |

## 《学习观》的下上结构

依据于建国《学习观：从感觉懂了到真正学会》关于「下上结构」、判别模型、联结模型与学习验证的论述。以下是用于伴读的转述；讲解安排是本技能的应用设计。

**下层是实际问题，上层是理解问题的工具。** 下层放这次要理解的具体对象、情境及其变化；上层放相关概念与概念之间的通用关系。作者将「下」放在前面，强调实际问题优先。两层是相对的：这次作为工具的概念，换个问题也可以成为研究对象，不能把「下」固定成物质、「上」固定成语言。

**判别模型接通对象与概念。** 它回答「眼前这个情况，凭什么算这一类？」讲一个概念时，要让读者看见所指、归类依据，以及容易混淆的边界。定义或名称本身不足以证明读者能在新情境认出它。

**联结模型接通概念之间的关系。** 它回答「知道了这一类情况，在什么条件下能推出什么？」归类正确与关系成立要分别说明；会背规律不保证会识别适用场景，认出类别也不自动证明规律。

**材料和验证承担不同作用。** 具体例子帮助建构，抽象表述帮助整理，未见情况用来检验迁移。复述已讲例子不足以证明会迁移；给出新情境、请读者判断并观察回答，才可能发现理解断在哪里。没有读者反馈时，只能说讲解提供了迁移检查，不能声称读者已学会。

## 讲解约定

### 原文与范围

- 先读到实际内容。粘贴文本直接使用；文件读取指定内容；URL 用当前可用的网页获取能力。拿不到正文时说明缺口，不根据标题或摘要补写全文。
- 围绕用户给定范围讲解。短段可直接深入；长文按完整语义单元组织，保留主线、重要分支与转折，不逐句平均用力，不切断承重论证。
- 中文直接解释。英文先给自然、准确的中文译文，保留影响判断的英文短句或术语作为校验锚点；仅在语言歧义、行话或文化典故影响理解时补充说明，不固定叠加三套翻译。

### 把下层与上层接通

先用一句普通话点明作者在回答什么问题、作出什么判断。随后围绕承重处展开，通常从一个能看见细节的情境进入，再提炼概念与关系，最后回到具体情境说明所得判断。安排随文本而变；以下是讲清楚的要求，不是必须逐项打印的栏目。

- **让事情可见。** 优先使用原文例子；原文太抽象时补一个贴近日常的教学设例，并就地标明。例子有具体的人或对象、条件、变化与结果；「好人也会死」这类只给抽象词加限定的句子，不能替代真正的下层材料。
- **让概念可辨。** 用普通话说明关键概念是什么、与相邻概念差在哪里。结合例子指出哪些事实使它属于这一类；容易误认时给一个只差关键条件的近邻情境。仅有描述或比喻时，保留其模糊处，不替作者发明精确标准。
- **让关系可追。** 把作者从前提走到结论的关键一步展开，说明中间发生了什么、依靠哪些条件。区分定义、分类、相关、因果、类比、价值判断和行动主张；箭头或公式按实际关系使用，不把所有文字改造成因果定律。
- **让两层对得上。** 明说例子里的什么对应哪个概念，凭什么对应；若有预测，再说明如何使用关系、所得结果在例子里意味着什么。不能从生活故事直接跳到大道理，也不能把抽象结论换个说法就当作讲解。
- **让边界改变判断。** 选能触及承重前提的条件变化、反例或未决处，说明它使归类变化、关系失效，还是只收窄结论。原文没有足够依据时留下未知，不为了完整替作者补成已证实的机制。
- **让迁移可检查。** 适合迁移的内容可收一个与已讲例子不同的小情境，让读者判断「是否适用、依据是什么、能推出什么」。默认可附简短参考分析；若用户选择互动自测，先只给题，等其回答再反馈。答案揭晓后，该题就属于讲解材料。

论证文本重在概念、依据与推理；叙事或抒情文本重在具体处境、人物变化、意象与表达效果。解释人物动机时区分原文所示与推测，诗意和多义性可以保留，不强求预测公式或唯一答案。

### 对话成品

默认中文 Markdown，以连贯段落讲解。短文本不硬分章；长文本用贴合内容的小标题。并列比较才用表格，承重关系确实难以看清时才加简短文本图或公式；符号先解释，再使用。

正文应让读者看见原文的主要意思、概念与情境的对应、推理的成立条件，以及一个足以改变判断的边界。结尾用一句话收住最值得带走的理解；不例行堆术语表、延伸书单或强制读后提问。

原文陈述、解释者的推论、补充教学设例分清。引用限于讲解所需，避免大段复刻受版权保护的来源。补充理论、事实或外部引文需有可核对来源；类比说明对应和失配处，不冒充证据。

**伴读结果默认只展示在对话中。** 不自动创建或更新笔记、Org 文件、对话记录、学习档案、记忆或其他产物，不返回虚构的文件路径。原文保持只读；用户另行明确要求保存或修改时，以其指定范围为准。

## 可选交互

- **默认**：连贯讲完当前范围，提问不作为继续讲解或完成交付的门槛。不推测读者已理解，不强制读者表态。
- **快进**：压缩铺陈与次要解释，保留主判断、关键对应与适用条件。
- **展开**：针对卡住的位置补具体例子、概念辨析、推理步骤或边界，不重新重复整篇。
- **等一下**：停在当前位置，处理读者指出的疑问。
- **提问伴读／互动自测**：一次只围绕一个真实缺口提问，等回应再推进。答错时定位归类、关系或条件哪处断开，用针对性材料修正，不以「说服了没有」替代理解检查。

## Gotchas

- 「下上结构」用于检查具体与抽象是否接通；它不要求每段都打印「下层／上层」或画成固定三层图。
- 多个例子若只换姓名或数字，可能仍在重复同一个表面形式。需要时改变情境或关键条件，检查读者是否掌握归类依据。
- 原文的结论强弱和证据范围应保留。一个教学例子、一次正确回答或模型间的一致，均不足以证明普遍规律或读者已经掌握。
- 通俗表达保留承重区别。类比不能替代定义，故事不能替代机制，反例不能靠偷偷改题制造。
- 听懂、认同、记住与会用分别判断；没有回答或实际应用证据时，不评定学习成败。

## Examples

- `/ljg-read 「激励会改变人的行为。」`：用有条件的教学设例讲清「激励」「行为变化」的对应，解释作者主张的关系；区分行为增加与目标改善，并指出原句尚未限定的条件。
- `陪我读这段英文，直接讲透`：给自然中文译文，在关键原句处核对；用具体情境、概念辨析与承重推理完成解释，直接在对话中交付。
- `这段我感觉懂了，换个例子考考我`：给未讲过的情境，先不揭答案；根据读者实际回答定位归类、关系或条件的缺口，不创建学习记录。

## 交付检查

读回解释与原文：主要意思和重要分支是否保留，关键概念能否在具体情境中辨认，关系的依据与条件是否清楚，补充例子是否标明，边界是否真的会改变判断。检查只证明当前讲解覆盖了这些要素；读者是否学会，仍需其反馈。
