# 从现象到有依据的机制

研究围绕一个对象反复运行：观察引出猜想，猜想提出区别性预测，材料检验预测，结果返回观察或过程。四个环节可以来回修正；新证据改变对象或口径时，应重建解释，不能把旧解释机械套回去。

## Step 0 — 范围与材料充分性

读取用户提供的现象、材料与当前上下文，区分亲历观察、转述、概括和待验证主张。明确用户要解释的结果，避免把收入问题换成生产率问题、把现象研究换成行动方案。

影响机制选择的对象、指标、时段或比较基准缺失时，先检索可以补足的公开材料；安全且可用的假设用一句话说明后继续。仅当不同理解会造成实质不同的研究对象、现有材料又无法消歧时，集中询问最少必要信息。未知的个体经历、组织内部过程和私人数据，不能用行业平均或教学设例填成事实。

默认联网。使用当前环境实际提供的搜索和内容获取工具；不得声称调用不存在的工具或搜索已经完成。搜索查询只携带研究所需的通用信息，不把原始私密材料发送给外部服务。

## ① 看反常：让观察与预期分开

本环节应得到一个准确的观察、一个可追问的预期，以及二者间真正需要解释的差异。

- 观察：什么对象，在什么范围与时间，相对什么基准，出现了什么变化？数据依据是什么？
- 预期：原以为哪些条件应带来哪些结果？这条预期依赖什么被省略的关系？
- 差异：缺了预期条件却出现结果；有了预期条件却没有结果；或同样条件下出现不同结果。

不用强行制造惊讶。某种常见秩序怎样维持、熟悉工具承担了什么隐藏功能，也可以成为有效难题。

先核对现象的口径与规模。搜索可观察指标、原始数据和反向案例，检查选择性样本、分母变化、指标替换和时间尺度。把「有些人如此」扩成「所有人如此」，或把「短期未体现」扩成「永远无效」，会产生错误的解释任务。

原始概括不成立时，说明保留了哪些事实、研究问题如何改变，再研究真实存在的差异。不要为了走完框架而解释一个并不存在的现象。

## ② 追过程：把解释落到动作和中间变化

选择能承载问题的具体对象，追踪「谁感知了什么 / 为什么调整 / 首先改变哪个量 / 怎样传到最终结果」。可以包含反馈、约束、选择、滞后或分配关系，不强求所有机制都是线性因果链。

关键概念有可辨认的所指，中间环节有观察地址，例如订单、成交价、等待时间、返工率、决策记录、资源流向或参与者行为。无法获得中间记录的地方，明确标为推断。

教学设例帮助读者运行关系，数据、人物、事件和结果须就地标为设例。不能把设例的正确演算当作现实机制已经成立。

提出最有解释力的机制猜想，并保留足以争夺同一结果的竞争解释。候选的差异应在关系或成立条件上，不只是给同一条机制换几个名称。通常少量候选即可；数目由问题的实质分歧决定。

分别说明每个候选依赖的关键条件、预计首先出现的变化，以及削弱或推翻它的观察。不同机制可以并存；需要判断它们作用于哪个环节、哪类对象和哪个时间范围。

## ③ 分解释：让联网材料区分候选

### 区别性预测

在用材料筛选候选前，把容易事后迁就的预测写清楚：假说成立时会先看到什么；竞争解释会给出什么不同结果；哪种观察会使自己改口。新的机制可随证据提出，但不能把看到结果之后补写的预测当成事前验证。

如果各个候选在现有条件下都预测同一结果，暂时无法区分。寻找新的观察位置或条件变化；不以解释更顺口、引用更多作为胜负依据。

### 检索要命中承重关系

检索既服务现象核验，也服务关键因果与竞争解释。围绕最有区分力的关系交替搜索支持、反例、相反结果和替代机制；搜索对象不能始终只是首选假说的术语。

| 要检验的内容 | 更有用的材料 |
|---|---|
| 现象是否发生、影响哪些对象 | 原始统计、指标定义、完整研究结果、可核对的记录 |
| 中间环节是否按预测变化 | 行为或交易记录、过程数据、实地观察、原始实验 |
| 某个因素是否造成结果 | 随机实验、可信的准实验或明确因果识别；观察研究需说明混杂与选择限制 |
| 哪种竞争解释更接近事实 | 相同口径的对照、关键条件变化、时序差异、未被原模型解释的案例 |
| 换个现场能否迁移 | 条件明确的独立样本、不同情境下的检验、反向案例 |

一手材料优先：原始论文、数据与方法、官方指标和规范、直接过程记录。评论与综述可帮助发现来源、提出候选；直接当事人的叙述有价值，也要考虑其观察位置与利益。

发现重要来源后读取相关正文、方法或数据说明，核对对象、时期、比较组、指标和实际结论。只拿到摘要或搜索片段时，把支持限于可读部分，说明无法检查的方法或机制细节；不要把付费墙后的内容补成已读。

研究发布日期与被研究事件的日期分开。较新的论文不一定研究最新时期；公开事实可能变化时，用当前材料核对。不同网页转述同一研究仍是同一份证据；模型间一致也不是独立现实证据。

### 证据落到关系上

对承重关系核对：来源实际测到什么，作者如何推断，自己的解释又增加了什么。能证明结果变化的材料，不一定测量了中介过程；总体相关也不自动说明个体因果。

材料的价值取决于它能改变什么判断。可以在内部使用下面的短表，成品只呈现最关键的几项：

| 关系或候选 | 区别性预测 | 实际观察与直接来源 | 支持范围 / 替代解释 / 剩余缺口 |
|---|---|---|---|

不要把「未显著」「没搜索到」或低检验能力下的零结果写成机制不存在。相反结果要检查是否在先前声明的适用范围内；条件相同而预测失败时，应修改关系，而不是只改表述。

### 更新与停止

证据可以保留、降低、排除或重建候选。冲突可能来自机制并存、对象不同、时段不同或最初口径错误，不能把冲突平均成一个模糊结论。

反例迫使范围收窄时，说明原预测哪里失效、新边界有什么依据、新解释会推出什么区别性结果。持续增加例外但不改变任何预测，属于保护解释，不能算机制变扎实。

停止于对当前范围有足够依据的判断，或停止于已识别且公开检索无法补足的关键缺口。关键关系已有支持、主要竞争解释已有比较时，不为增加链接数重复检索。新的搜索只反复得到同源转述、关键区分依赖不可获取的数据时，交付限制与下一条最有价值的观察。

证据强度按承重关系与区分能力表达，不凭主观分数或链接数量评定：

- **机制在所述范围内有支持**：关键过程有现实依据，因果识别或过程证据足以支撑相应措辞，重要竞争解释得到检验；说明尚存的不确定性。
- **当前领先解释**：能解释已有观察，但关键因果或区分证据仍缺失；指出领先理由及具体缺口。
- **尚无法区分**：多个机制仍能解释同一观察；并列保留，指出最能区分它们的下一条数据。
- **原始观察需要改写**：核验发现口径错误或概括过度；研究修正后的对象，保留用户观察中仍成立的部分。

研究者对总体结论的评价，不自动提升每条关系的强度。联网不可用时，仅能交付推演与检验设计；不能使用「已验证」或声称得到 solid 的实证机制。

## ④ 带条件迁移：检查解释能否推出新结果

从具体对象抽出「在条件下，通过某种关系生成结果」。保留行动者、信息与资源约束、作用方向和时间尺度；抽掉领域名称不能同时抽掉承重条件。

先沿同一个对象改变一个关键条件，写出预计最先变化的量和最终结果。这个反事实用于检验内部关系，尚未实施或取得独立数据时仍是推演。

再用一个不同情境检查对象和变量能否对应、关键条件是否存在，以及所得预测是什么。类比和已经揭晓答案的设例只说明可理解的迁移路径；未经独立现实材料检验，不能升级为跨域规律。

机制是否值得带走，看它是否会改变新的预测、判断或行动。用户只要求解释时，给判别抓手；不要擅自转成执行方案、实验、发布或持久化。

## 交付检查

成品应直接回答现象，讲清可运行的关系，给出关键来源、与竞争解释的比较、适用条件和修改入口。只在会改变判断的地方标明事实、推断、猜想与未知，不把证据标签铺满每句话。

短答不必打印全部四步；完整示范按四步展开。结尾留下当前最可靠的机制判断，以及一条足以使它改口的观察。完成的是所述范围内的研究，有限材料不能证明普遍规律。
