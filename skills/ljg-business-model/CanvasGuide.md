# 商业模式画布：分类与空间合同

依据 Alexander Osterwalder、Yves Pigneur 的《商业模式新生代》（Business Model Generation）及 Strategyzer 官方 Business Model Canvas。以下为要点归纳与中文改编，未声称逐页复核整本书。

## 九个模块

| JSON 键 | 模块 | 这格回答什么 | 与邻格的边界 |
|---|---|---|---|
| customer_segments | 客户细分 | 为哪类人／组织创造价值？谁使用，谁付款？ | 避免「所有人」；平台两边分别写 |
| value_propositions | 价值主张 | 客户在哪个场景得到什么结果，为什么选择它？ | 产品功能要接到客户收益；不要只写口号 |
| channels | 渠道通路 | 客户怎样发现、评估、购买、获得交付与售后？ | 按路径写，避免只罗列社交平台 |
| customer_relationships | 客户关系 | 怎样建立、维持、深化与客户的关系？ | 人工服务、自助、社群、共同创造等互动机制 |
| revenue_streams | 收入来源 | 谁为什么价值付款，按什么单位／周期收费？ | 融资不是收入；标清一次性与持续收费 |
| key_resources | 核心资源 | 实现价值必须具备哪些资产或能力？ | 场地、设备、品牌、数据、人才、资金等存量 |
| key_activities | 关键业务 | 为实现价值必须持续做哪些事？ | 描述动作；别把资产名重复放进来 |
| key_partners | 重要合作 | 依赖哪些外部伙伴，分别提供什么？ | 普通客户不自动成为伙伴；采购关系按必要性取舍 |
| cost_structure | 成本结构 | 哪些活动／资源消耗成本，主要由什么驱动？ | 固定与变动支出；金额与周期保持来源口径 |

客户细分决定价值主张的对象；渠道和关系把价值交到客户手中；业务、资源与伙伴承接交付；收入和成本说明价值如何被获取及其代价。检查对应关系，不为凑齐关系制造材料里没有的内容。

## 经典布局

```text
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│          │ 关键业务 │          │ 客户关系 │          │
│ 重要合作 ├──────────┤ 价值主张 ├──────────┤ 客户细分 │
│          │ 核心资源 │          │ 渠道通路 │          │
├──────────┴──────────┴────┬─────┴──────────┴──────────┤
│        成本结构          │        收入来源           │
└─────────────────────────┴───────────────────────────┘
```

标题区包含对象、范围／阶段、日期／版本及一句话概括。日期使用任务所在时区。画布默认横版，信息密度优先于强行保持某个长宽比。每条状态标签与来源编号都可见；完整来源摘要保留在 JSON，避免在卡片页脚堆满访谈原文。
