# 共同品味底线

三种模具可以完全不同，但都必须让「判断」先于「装饰」。

## 1. 视觉必须有工作

每一幅生成图都要能回答：它让读者看见了哪一句话单靠文字不容易看见的东西？

- 有动作、有对象、有冲突；少用抽象光线、漂浮几何和通用 AI 意象。
- 不因版面空就补图。删掉图片后理解不变，这张图就不该生成。
- 同一成品内不要重复同一隐喻、同一镜头或同一资产。
- 原文图片是证据时，保真引用并标注来源；不能重生成后冒充原图。

## 2. 图文各司其职

- 生成图：人物、物件、场景、动作、空间关系、情绪张力。
- HTML/CSS：标题、正文、数字、公式、坐标、标签、箭头、批注、来源。
- 图中禁止可读文字、字母、数字、Logo、水印、伪标签和伪界面。
- 每个图片槽都有具体 `alt`，描述图中动作及其与正文的关系；禁止写「配图」。

## 3. 版式不要平均

- 禁止把内容机械切成三等分、四等分或一排相同卡片。
- 留白跟着叙事节奏走：转折与结论可以放大，铺垫应收紧。
- 一页只有一个主视觉焦点；其他元素服务它。
- 图片构图必须提前给标题区、正文区或标注区留安全区，不能事后压字补救。

## 4. 字与颜色

- 禁用 Inter；优先 mode 指定字族与中文系统字族。
- 正文不用纯黑 `#000000`，用暖黑或深灰。
- 主色要有角色，不把五六种高饱和颜色平均分给模块。
- 不用渐变、厚阴影、玻璃拟态、发光边框制造「高级感」。
- 字号按 1080px 成品检查，不用桌面网页字号直接截图。

## 5. 中文与事实

- 判断 → 机制 → 边界；少写「赋能、重塑、构建、深度、全新」等空词。
- 不编数字、引语、机构、人名或来源。
- 不把解释写进生成图，再依赖模型拼字。
- 每句默念一遍：像中文口语或成熟书面语，不像翻译腔与模板腔。

## 6. 禁止伪完成

- 不使用远程随机图、占位图、假 logo、坏链图片。
- 不用 CSS 图标或矢量图冒充已经完成的概念主视觉。
- 图片工具不可用、语义错误或含伪文字时，最多定向重生两次；关键图仍失败就阻断。
- 能打开 HTML 不算完成；必须得到 PNG 并做像素读回。

## 7. 最终视觉检查

- 视觉层级：三秒内能找到标题、主判断和下一步阅读方向。
- 语义：每图能回指一个源判断，没有通用装饰图。
- 图像：无伪文字、无品牌污染、无主体裁切、无重复资产。
- 文字：无溢出、遮挡、过小字号、孤行或来源漂移。
- 长图：整图一次，顶部/中段/底部重叠切片覆盖全部高度。
